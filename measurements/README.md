# 測定の記録

**ここは「測ったが、コードには何も残らなかったこと」の置き場です。**

結論が「触らない」だった測定は、テストにもコードにも残せません。
けれど**次に同じ議論が起きたとき、ゼロから測り直すのは無駄**です。そのために残します。

## 何を残すか

| 残す | 残さない |
|---|---|
| **やらないと決めた測定**（本文に除外語を当てると天領さんが消える） | **テストに固定できたもの**（`tests/` が生きた記録になる） |
| **情報源の下調べ**（川本町のフィードは記事0件） | 1回きりの件数確認 |
| **語彙の効果測定**（`sidebar` を足すと公開中5件の本文が消える） | デバッグの途中経過 |
| **窓・在庫の実測**（はまナビは最も狭い） | 収集ごとの増減 |

**目次に1行で書けないものは、残す価値がありません。** 下の目次に足せなければ捨ててください。

## 書き方

`YYYY-MM-DD-なにを測ったか.md`（ファイル名は英数字、中身は日本語）。
冒頭に **測ったもの / データ / 結論** の3つを書きます。

**数字はここにだけ置きます。** `CLAUDE.md` と `ISSUES.md` からは参照するだけで、
写しません（設計判断15）。

## 手入れ

**年1回、この目次を見て、もう効かないものを消してください。**
情報源のサイトが作り替われば、その下調べは意味を失います。
